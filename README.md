# The World Today — 22 November 2026

One image summing up 22 November 2026's world news: 10 illustrated
stories, 17 numbered briefs, and a schematic world map with numbered
pins, drawn entirely by `main.py` (Python standard library only).

Run: `MAKEFUN_OUTPUT_DIR=out python3 main.py` writes `out/entry.png`
(1024x1024 PNG, deterministic: two runs write identical bytes).
